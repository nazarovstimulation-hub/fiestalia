# Анализ испанского рынка: QR-фотоальбомы для событий

Дата: октябрь 2026. Источники — публичные страницы сервисов и обзорные статьи (часть обзоров написана самими конкурентами, цены стоит перепроверять на их сайтах перед запуском).

## 1. Что такое FotoToi (референс)

[fototoi.com](https://fototoi.com/) — русскоязычный сервис (ориентирован на Казахстан и РФ: оплата Kaspi, Prodamus): «QR-фотоальбом гостей с поиском по лицу».

Ключевые элементы продукта и лендинга, которые перенесены на испанскую версию:

| Элемент FotoToi | Испанская версия (`site/`) |
|---|---|
| Гости сканируют QR, грузят фото и видео без приложения и регистрации | Hero + «Cómo funciona» (4 шага) |
| Поиск по селфи | «Búsqueda por selfie» + отдельный FAQ о приватности (RGPD) |
| Live Wall: фото появляются на LED-экране в зале, ведущий объявляет | Секция «Live Wall» с анимированным макетом экрана |
| Лента, слайдшоу, скачивание архивом | Карточки «Galería en tiempo real», «Descarga en ZIP» |
| 50 фото бесплатно | `freePhotos: 50` в `brand.js`, упоминается во всём тексте |
| Разовая оплата, без подписки; цена зависит от числа кадров и ГБ | Блок «Precios»: pago único, тарифы по объёму |
| Число гостей у тарифа — это калькулятор (≈25–30 кадров на гостя), не лимит | Интерактивный слайдер «¿Cuántos invitados tendrás?» + FAQ |
| FAQ | 8 вопросов, адаптированных под Испанию |

### Выводы

1. **Ниша свободна.** В Испании нет массового сервиса, который объединяет «QR без приложения + поиск по селфи + Live Wall + разовая оплата». Поиск по лицу есть только у американского GuestCam (дорого, на английском) и у B2B-решений для фотографов.
2. **Ценовой коридор** разовой оплаты на испанском рынке — 19–49 € за событие (Momentshare, Eventocam, Easy Wedding Album). Тарифы в `brand.js` (0 / 19 / 39 / 69 €) попадают в него, а «Gran evento» за 69 € — верхняя планка для корпоративов и больших свадеб.
3. **Главный аргумент против WedShoots** — обязательное приложение. Поэтому «Sin app, sin registro» вынесено в hero и в таблицу сравнения.
4. **Хостинг в ЕС и RGPD** — рабочее УТП (его уже использует Momentshare). В FAQ заявлено «servidores en la UE» — это нужно реально обеспечить при выборе хостинга.
5. **LatAm как второй рынок:** тот же сайт покрывает Мексику/Чили/Аргентину, если добавить quinceañeras (уже есть в секции «Eventos») и оплату в местной валюте.

## 3. Юридический момент: распознавание лиц в Испании

Поиск по селфи = обработка **биометрических данных** (категория особых данных по RGPD, ст. 9, и LOPDGDD). Испанский регулятор AEPD уже штрафовал за распознавание лиц на мероприятиях: 200 000 € организатору MWC 2021 за отсутствие предварительной оценки воздействия (DPIA), хотя согласие собиралось.

Что нужно до запуска функции в продакшн:

- **Явное отдельное согласие** гостя именно на биометрическое сравнение (общее согласие на фото не покрывает). В FAQ сайта это уже заявлено как принцип работы.
- **DPIA** (evaluación de impacto) — обязательный документ.
- Сравнение только внутри альбома, удаление селфи сразу после поиска, возможность владельцу альбома отключить функцию (всё это описано в FAQ — реализация должна соответствовать).
- Альтернатива для тех, кто не согласен (обычная галерея).
- Política de privacidad, aviso legal, cookies — ссылки в футере пока заглушки.

## 4. Что ещё стоит добавить (бэклог)

- Страницы под ключевые запросы: «álbum QR boda», «compartir fotos boda sin app», «código QR fotos boda» — конкуренты активно закрывают SEO блогами.
- Реальные отзывы вместо демонстрационных в секции «Opiniones».
- Фотозадания («retos fotográficos») — есть у BodasPro, хорошо работают на вовлечение.
- Бесплатный шаблон карточки QR для печати (lead magnet).
- Листинг на Bodas.net как поставщик (так делает Eventocam).
